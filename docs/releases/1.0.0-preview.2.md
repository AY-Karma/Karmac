# Karmac 1.0.0-preview.2

Portable Windows x64 preview. Extract the ZIP and run `Karmac.exe`, keeping its
`.config` alongside it. Requires Windows 10/11, .NET Framework 4.8, and Bluetooth
drivers. Pair your headphones once in Windows before connecting.

- Fixes unnecessary idle CPU use from a hidden indeterminate progress animation.
  The indicator stops when idle, hidden in the tray or minimized, and respects
  Windows' animation preference.
- Adds the original ivory/amber signal-K app icon, including small Windows tray sizes.
- Updates public-use documentation, update instructions, reporting guidance and artwork attribution.

To update from preview.1, quit Karmac, extract this ZIP into its application
folder and launch it again. Settings remain in `%LOCALAPPDATA%\Karmac`.

## Known limits

Only AirPods Pro 3 has physical connection observations on the development laptop;
other recognized models have catalog/synthetic UI checks. Prior connection
measurements are not benchmarks of this build. Battery readings depend on Windows
and the device; manual nearby sources remain explicitly unverified. See
`docs/compatibility.md` and `docs/metrics.md` in the ZIP.

Switching off disables **all laptop Bluetooth by default**. Select headphones-only
disconnection in Settings to leave other Bluetooth devices connected.

**Unsigned preview:** Windows may warn or block the app. Compare the ZIP and EXE
against `SHA256SUMS.txt` from the same release. See `docs/windows-trust.md`.
There is no installer, automatic updater, account or application analytics.
