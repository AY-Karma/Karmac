# Karmac 1.0.0-preview.1

Initial portable Windows x64 preview. Extract the ZIP and run `Karmac.exe`; keep its `.config` alongside it. Requires Windows 10/11, .NET Framework 4.8, and working Bluetooth drivers. Pair the headphones once in Windows.

- One action enables Bluetooth when needed, revalidates the saved pair, requests the audio connection, and verifies Windows playback roles, with live progress.
- Main-screen connection switch, tray/hotkey access, model-aware illustrations, and available battery readings.
- Switching off disables all laptop Bluetooth by default. Settings offers headphones-only disconnection so other Bluetooth devices can stay connected.
- Renamed from the development name OpenConnect. Existing local settings and artwork remain readable as fallbacks; new settings are saved under Karmac.

## Known limits

Only AirPods Pro 3 has physical connection observations on the development laptop. Other catalog models have synthetic/catalog/UI validation. Two prior cold-connect observations were 4.674 s and 15.493 s; a separate already-connected check was 211 ms. These observations predate this release build and are not a fresh benchmark, a guarantee, or a speedup over Windows. No Windows baseline or first-audible-sound latency was measured.

The tested Pro 3 broadcasts could not be automatically tied to the paired device's rotating identity. Battery values can remain unavailable; manual nearby sources are explicitly unverified. Recognized artwork does not imply complete battery or Apple ecosystem feature support. See `docs/compatibility.md` inside the ZIP.

**Unsigned preview:** Windows may warn or block it. Check `SHA256SUMS.txt` supplied beside the ZIP and see `docs/windows-trust.md` inside it. There is no installer, auto-update service, account, or application analytics. `PRIVACY.md` and `SECURITY.md` are included.
